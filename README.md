# WebLarek Express

Интернет-магазин с административной панелью для управления товарами. Полнофункциональное веб-приложение с разделением на клиентскую и серверную части.

## 📋 Описание проекта

WebLarek Express — это современный интернет-магазин, позволяющий пользователям просматривать каталог товаров, добавлять их в корзину и оформлять заказы. Администраторы могут управлять товарами через специальную панель управления: создавать, редактировать и удалять товары, а также загружать изображения.

### Основной функционал

- **Для пользователей:**
  - Просмотр каталога товаров
  - Добавление товаров в корзину
  - Оформление заказов с указанием контактных данных и адреса доставки
  - Регистрация и авторизация

- **Для администраторов:**
  - Управление товарами (CRUD операции)
  - Загрузка изображений товаров
  - Просмотр и управление заказами

## 🛠 Стек технологий

### Backend

- **Node.js** — серверная платформа
- **Express.js** — веб-фреймворк для Node.js
- **TypeScript** — типизированный JavaScript
- **MongoDB** — NoSQL база данных
- **Mongoose** — ODM для MongoDB
- **JWT (jsonwebtoken)** — аутентификация и авторизация
- **bcryptjs** — хеширование паролей

- **Celebrate** — валидация запросов

- **CORS** — настройка кросс-доменных запросов
- **Cookie-parser** — работа с cookies
- **Node-cron** — планировщик задач (очистка временных файлов)

### Frontend

- **React 18** — библиотека для создания пользовательских интерфейсов
- **TypeScript** — типизированный JavaScript
- **Vite** — инструмент сборки и разработки
- **Redux Toolkit** — управление состоянием приложения
- **React Redux** — интеграция Redux с React
- **Redux Persist** — сохранение состояния в localStorage
- **React Router DOM** — маршрутизация
- **React Toastify** — уведомления
- **SASS/SCSS** — препроцессор CSS для стилизации
- **React Input Mask** — маски ввода для форм

### DevOps

- **Docker** — контейнеризация приложения
- **Docker Compose** — оркестрация контейнеров
- **Nginx** — веб-сервер и reverse proxy

## 🚀 Установка и запуск

### Предварительные требования

- Node.js (версия 18 или выше)
- Docker и Docker Compose
- npm или yarn

### Локальная разработка

#### Backend

```bash
cd backend
npm install
npm run dev
```

Backend будет доступен на `http://localhost:3000`

#### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend будет доступен на `http://localhost:5173`

### Запуск с Docker

1. Создайте файлы `.env` в директориях `backend/` и `frontend/` с необходимыми переменными окружения

2. Запустите контейнеры:

```bash
docker-compose up --build
```

Приложение будет доступно на `http://localhost:80`

### Переменные окружения

#### Backend (.env)

```env
PORT=3000
DB_ADDRESS=mongodb://mongo:27017/weblarek
ORIGIN_ALLOW=http://localhost:5173
JWT_SECRET=your-secret-key
```

#### Frontend (.env)

```env
VITE_API_URL=http://localhost:3000
```

## 📡 API Endpoints

### Товары

- `GET /product` — получить список товаров
- `POST /product` — создать товар (требуется авторизация)
- `PATCH /product/:productId` — обновить товар (требуется авторизация)
- `DELETE /product/:productId` — удалить товар (требуется авторизация)

### Заказы

- `POST /order` — создать заказ

### Аутентификация

- `POST /auth/signup` — регистрация
- `POST /auth/signin` — авторизация
- `POST /auth/signout` — выход

### Загрузка файлов

- `POST /upload` — загрузка изображения товара

## 📝 Логирование

Приложение использует Winston для логирования:
- HTTP-запросы логируются через express-winston
- Ошибки записываются в отдельный файл
- Консольный вывод для разработки

## 🗄 База данных

Проект использует MongoDB для хранения данных:
- Модель `Product` — товары магазина
- Модель `User` — пользователи системы
